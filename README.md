# CampusFlow — Практическая работа №1

Учебный веб-сервис для поиска и записи на мероприятия.

## Команды

| Действие | Команда |
|----------|---------|
| Запуск dev-сервера | `npm run dev` |
| Сборка | `npm run build` |
| Проверка ESLint | `npm run lint` |
| Автоисправление ESLint | `npm run lint:fix` |
| Форматирование (Prettier) | `npm run format` |
| Проверка CSS (Stylelint) | `npm run stylelint` |
| Автоисправление CSS | `npm run stylelint:fix` |

## Структура проекта

- `src/components/` — переиспользуемые компоненты
- `src/pages/` — страницы
- `src/styles/` — CSS-файлы
- `docs/decomposition.md` — декомпозиция макета

## Стек

Vite + Vanilla JS + ESLint + Prettier + Stylelint
